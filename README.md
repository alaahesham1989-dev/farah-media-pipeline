# farah-media-pipeline — ميديا المنتجات (منفصل عن متجر فرح)

مشروع لوحده: بينقل صور وفيديوهات المنتجات من درايف المورد لمخزن خام على السحابة، ومنه بنجهّز
ميديا السوشيال والمتجر. **مابيكتبش أي حاجة في قاعدة بيانات متجر فرح** — النتيجة النهائية بس
هي اللي بتتنقل للمتجر بعد ما نختار.

```
درايف صفقة (عام)  ──►  GitHub Actions (كمبيوتر سحابي مؤقت)  ──►  R2: farah-raw  (المخزن الخام)
                                                                   │
                                                                   ▼
                                              معالجة (اسم المتجر/اللوجو، مقاسات، مونتاج)
                                                                   │
                                                                   ▼
                                     الجاهز بس ← مخزن الموقع farah-media + منتجات فرح (بعد الاختيار)
```

## الملفات
| الملف | بيعمل إيه |
|---|---|
| `catalog/safka-catalog.json` | كتالوج صفقة: اسم، كود، تكلفة، سعر مقترح، لينك الميديا، صور |
| `catalog/files.json` | كل ملفات الدرايف لكل منتج (بيتعمل بـ `npm run list`) |
| `scripts/transfer.mjs` | بينقل الملفات للمخزن الخام — بيكمّل من مكان ما وقف |
| `scripts/match-farah.mjs` | بيقارن منتجات فرح بصفقة (قراية بس) → `reports/match.md` |
| `.github/workflows/transfer.yml` | تشغيل النقل على السحابة بضغطة زرار |

## التشغيل
1. `npm install`
2. `npm run list` — قايمة الملفات (مش محتاج مفاتيح)
3. `npm run match` — تقرير المقارنة (مش محتاج مفاتيح)
4. النقل: GitHub → Actions → "نقل الميديا للمخزن الخام" → Run workflow

## المفاتيح (GitHub → Settings → Secrets and variables → Actions)
`R2_ACCOUNT_ID` · `R2_ACCESS_KEY_ID` · `R2_SECRET_ACCESS_KEY` · `R2_BUCKET` (= `farah-raw`)
المفتاح لازم يكون على bucket `farah-raw` بس (Object Read & Write) — مش على مخزن الموقع.
**ماتحطش المفاتيح في أي ملف في المشروع.**

## تنبيهات
- الميديا مسموح بيها للمنتجات اللي نفس الموديل بالظبط.
- صور أسماءها فيها `_AC_` جاية من أمازون — مانستخدمهاش في الإعلانات (حقوق).
- الفيديوهات كبيرة (لحد مئات الميجا) — `MAX_MB` بيتخطى الأكبر.
